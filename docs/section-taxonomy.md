# Section & group taxonomy

Canonical guide: [api-portfolio/docs/section-taxonomy.md](https://github.com/Muscadine-Labs/api-portfolio/blob/main/docs/section-taxonomy.md) (local: `../api-portfolio/docs/section-taxonomy.md`).

**Cash:** Physical → Short-Term (bank) → Long-Term (bank) → **DeFi Cash** (separate), with DeFi split into **Long-Term (Cold)** vs **Short-Term (Smart)**.

**Assets Crypto:** Bitcoin / Exchanges / Cold / DeFi / Hot — by custody and role, not mixed into bank groups.

**Sync:** set each wallet’s section links; Settings auto-route only chooses assets vs cash vs liabilities, not which DeFi subcategory.
